FUNPAY CONTROL CENTER — инструкция

1. Установка
   Python 3.11+ рекомендуется.
   pip install -r requirements.txt

   FunPay-клиент устанавливается из ZIP GitHub-репозитория напрямую.
   Git в контейнере для этого не нужен.

2. Настройка
   Скопируйте .env.example в .env и укажите:
   - BOT_TOKEN: токен Telegram-бота.
   - ADMIN_ID: ваш Telegram user ID.
   - FUNPAY_GOLDEN_KEY: cookie golden_key от авторизованного FunPay.
   - FUNPAY_USER_AGENT: User-Agent браузера, где выполнен вход.

   Не отправляйте .env и golden_key посторонним.

3. Запуск
   python main.py

4. Команды Telegram
   /start, /menu — панель
   /status — статус
   /help — справка
   /pause — общая пауза
   /resume — снять паузу
   /backup — резервная копия
   /stats — финансы за последние 24 часа
   /rules — редактор триггеров
   /cancel — отменить текущий ввод
   /ping — быстрая проверка Telegram/FunPay/SQLite
   /id — показать ваш Telegram ID

5. Автоответчик
   Панель → АВТООТВЕТЫ → Добавить триггер.
   Формат:
   contains | привет | Здравствуйте, {username}! | 10 | 60
   Режимы: contains, exact, regex.
   Последние поля необязательны: приоритет и cooldown в секундах.

6. Привязка лота
   Панель → ТОВАРЫ / СКЛАД → Привязать лот.
   Склад:
   LOT_ID | stock | Название лота | себестоимость_за_единицу
   Статическая выдача:
   LOT_ID | static | Название лота | текст выдачи

7. Импорт TXT
   Одна строка файла = одна единица товара.
   Отправьте TXT боту с подписью lot_id:123456.
   Повторно загруженные строки одного лота считаются дубликатами и не добавляются.

8. Защита выдачи
   При первой синхронизации текущие заказы импортируются как исторические и не выдаются автоматически.
   Это защищает от повторной отправки по старым покупкам. Все новые заказы после baseline проходят обработку.
   Перед отправкой позиции резервируются в SQLite и создаётся запись delivery.
   Если сетевой запрос завершился с неясным результатом, статус становится uncertain.
   Бот не повторяет такую отправку автоматически. Сначала вручную проверьте чат.
   Разрешайте повтор только если точно убедились, что покупатель товар не получил.

9. Автоподнятие
   Задайте явный allowlist ID лотов в разделе ТОВАРЫ / СКЛАД.
   Затем включите автоподнятие. Минимальный интервал в коде — 30 минут.
   Бот не делает случайные задержки для обхода правил площадки.

10. Каталог FunPay и репрайсинг
   Панель → ТОВАРЫ / СКЛАД → Каталог FunPay. Выбери подкатегорию, чтобы посмотреть свои лоты, цены и количество.
   Кнопка «Репрайсинг» принимает строки LOT_ID | НОВАЯ_ЦЕНА (до 10 лотов за раз).
   Бот загружает текущие поля формы и показывает предпросмотр; запись на FunPay выполняется только после нажатия «Подтвердить».
   Если для лота настроена себестоимость, проверяется, что цена покрывает себестоимость с учётом указанной комиссии.
   Импортированные TXT сохраняются в products/ и входят в ZIP-бэкапы.

11. Ограничения
   FunPay-клиент сторонний и неофициальный. Если FunPay изменит внутренние ответы,
   совместимость может измениться. Сначала тестируйте на тестовом лоте.
   В этой версии нет автоматических жалоб, автоответов на отзывы, создания новых
   лотов, массового включения/выключения или редактирования описаний, имитации
   онлайна. Репрайсинг существующих лотов реализован отдельно и требует подтверждения.
